# 音訊

## BGM
- `threshold-between-worlds.mp3`：〈Threshold Between Worlds〉，由專案作者以 Suno 生成（約 3 分 39 秒，循環播放）。
- 路徑設定在 `story.js` 的 `STORY.audio.bgm`。換曲時把新檔放進這個資料夾、改路徑，並更新 `STORY.version`。

## 音效
全部由 `audio.js` 以 WebAudio 即時合成，**沒有外部音檔，沒有第三方授權問題**。

| 音效 | 觸發時機 |
|---|---|
| 按鈕點擊 | 一般按鈕 |
| 材料選擇（木頭輕敲） | 點調酒台的材料 |
| 搖酒、倒酒、冰塊、杯子碰撞、推杯 | 送出酒（約 2.7 秒，期間調酒預覽卡會晃動） |
| 敲桌 | 點特殊客人 |
| 對話打字音／翻頁音 | 對話文字逐字出現／點擊下一句（依說話者換音高） |
| 鑼聲 | 事件標題卡出現 |
| 結算和弦（依星級）／低沉音（負好感） | 結算卡 |
| 解鎖閃光 | 解鎖新事件 |
| 氣流聲 | 場景淡入淡出 |
| 門聲、腳步聲 | 按「開始遊戲」進入酒吧 |
| 鐘聲 | 打烊 |
| 酒館低語＋偶爾的杯子聲 | 進入酒吧後的環境音 |

## 控制
- 入口頁與遊戲中右上角的 🔊 按鈕：音樂音量、音效音量、靜音（存在瀏覽器 `km_audio_v1`）。
- 對話與事件期間，BGM 會自動壓低到約 55%。
- 瀏覽器規定要先有使用者操作才能發聲，所以第一次點擊畫面任何地方後 BGM 才會開始。

## 調整合成音效
音效都在 `audio.js` 的 `makeSynth` 裡，每個是一個小函式（用 `tone` 與 `noise` 組合）。
`Sound.measure('音效名')` 可離線渲染並回報峰值與有聲長度，用來檢查是否有聲音、有沒有爆音。
